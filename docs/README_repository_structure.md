## Repository Structure

This project repository is organized as follows:

- **data**
  - Contains the primary dataset file used for analysis and modeling.

- **docs**
  - `code_of_conduct.md`: Guidelines and rules for project contributions.
  - `README.md`: Comprehensive project overview and usage instructions.
  - `team_work_contract.md`: Defines team responsibilities and collaboration guidelines.
  - `mongodb-databricks_setup.md`: Instructions for connecting MongoDB to Databricks.

- **config**
  - `environment.yaml`: Specifies the conda environment dependencies for the project.
  - `credentials_mongodb.json`: Stores MongoDB credentials (ensure this file is secured).

- **notebooks**
  - Contains Jupyter notebooks for exploratory data analysis (EDA), modeling, pipeline, and PySpark operations.

- **reports**
  - `project_draft.pdf` and `final_proposal.pdf`: Documents detailing project objectives, methodology, and outcomes.

- **scripts**
  - Contains scripts for EDA, data pipeline creation, and modeling processes.

- **tests**
  - Contains test scripts to validate the functionality and integrity of various components in the project.
